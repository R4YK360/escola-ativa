# EscolaAtiva - Aplicação Web de Gestão de Atividades Escolares

Aplicação Web desenvolvida no âmbito da disciplina de **Construção de Páginas Web (CPW)** do 12.º ano. Permite registar, consultar, filtrar, editar e gerir atividades escolares (como workshops, visitas de estudo e eventos), garantindo a persistência de dados no navegador.

## 🚀 Requisitos da Aplicação
* **R1:** Interface responsiva adaptada a computadores e telemóveis (com Bootstrap).
* **R2:** Componentes reutilizáveis (`AtividadeForm`, `AtividadeCard`, `FiltrosBar`).
* **R3:** Gestão completa de atividades (Adicionar, Listar, Editar e Eliminar).
* **R4:** Pesquisa em tempo real por título e filtros por estado (Pendentes / Concluídas).
* **R5:** Validação de formulários (impede o registo de campos obrigatórios vazios).
* **R6:** Interatividade dinâmica sem recarregar a página (Vue.js 3).
* **R7:** Persistência de dados utilizando o `localStorage`.
* **R8:** Separação coerente de componentes, lógica e estilos.

---

## 💻 Tecnologias Utilizadas
* **Vue.js 3** (com Vite)
* **Bootstrap 5** (para a estilização responsiva)
* **JavaScript (ES6+)**
* **HTML5 e CSS3**
